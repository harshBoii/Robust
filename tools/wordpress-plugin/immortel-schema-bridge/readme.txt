Publishes JSON-LD structured data generated by Immortel into your posts' page head.

== Description ==

Immortel generates schema.org structured data alongside every article it writes. This
plugin gives that data a home in WordPress:

* Registers two REST-writable post meta fields, `immortel_json_ld` and `immortel_payload`.
* Prints the stored JSON-LD graph into `wp_head` on single posts.
* Detects Yoast SEO and Rank Math, and merges Immortel's nodes into their existing graph
  rather than emitting a second, competing one.

Without this plugin, Immortel falls back to embedding the JSON-LD in the post body. That
still works for search engines, but only if the publishing user has the `unfiltered_html`
capability — WordPress strips `<script>` tags for everyone else. On multisite, only Super
Admins have that capability. Installing this plugin removes that constraint entirely.

== Installation ==

1. Upload the plugin zip via Plugins → Add New → Upload Plugin, or extract it into
   `wp-content/plugins/`.
2. Activate it through the Plugins menu.
3. In Immortel, open Profile → Integrations → WordPress and click "Verify site". The
   schema status should change to "Full schema".

No configuration is required.

== Frequently Asked Questions ==

= Does this conflict with my SEO plugin? =

No. When Yoast SEO or Rank Math is active, this plugin stops printing its own `<script>`
block and instead merges into their schema graph. It also defers to them for the page's
primary Article, WebPage, Organization, and BreadcrumbList nodes, contributing only the
node types they do not already model.

= What happens to my data if I deactivate it? =

The post meta stays in the database; only the head output stops. Reactivating restores it.
